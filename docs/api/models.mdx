# Models

Model classes are the main ORM surface for persistence and relation access.

## SQL models

Use SQL models for relational flows and SQL migration support.

## Mongo models

Use Mongo models for document-oriented persistence with Mongo runtime semantics.

## Tips

- Keep model classes thin.
- Register models at application bootstrap for deterministic behavior.
- Use factory files for reproducible test and demo data.
